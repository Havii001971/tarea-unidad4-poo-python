## Ejecución

Requiere únicamente Python 3, sin instalar paquetes. Desde esta carpeta:

```bash
python ej01.py
```

Cambiar `ej01.py` por el ejercicio deseado, hasta `ej13.py`.
Cada archivo incluye ejemplos independientes y no pide datos por teclado.
Las colecciones con prefijo `_` son internas por convención y se manejan
mediante métodos. En el ejercicio 3 se consideran 13 salarios; en el 11,
se aprueba con promedio de 60 o más.
